# リストマスター 対談台本（社内用）

西村果林 × 白石崇 の対談収録用スクリプト。バージョン 1.7。

## 取り扱い

**社内限定。外部公開しないこと。** 価格・機能・数字が未確認のまま入っている。
本文中のオレンジ色の「要確認」タグと、巻末の「収録前の確認事項」を潰してから収録する。

## 収録前に必ず決めること（巻末リストの上3件）

1. 06 のメール／FAX による初期営業が実装済みか。未実装ならそのくだりを丸ごと落とす
2. 1日の生成件数（この台本は 100社、公開中のLPは 300〜350件）をどちらに揃えるか
3. 01 の「販売件数が増えている」を対外で言ってよいか

## 構成

7ブロック／想定11〜13分。

| | ブロック |
|---|---|
| 01 | 最近、売れてるらしいですね |
| 02 | 新規の売上は、掛け算でできている |
| 03 | 新規営業って、何で決まるんですか |
| 04 | いちばん大事な仕事が、いちばん雑に扱われてる |
| 05 | 人が見つけられる会社は、競合も見つけてる |
| 06 | だから、掘る場所を毎朝変えさせてる |
| 07 | 条件は、狭くていい |
